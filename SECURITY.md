# Security Policy

## Supported Versions

Only the latest `0.x` release line is currently supported with security updates.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report vulnerabilities privately through **GitHub Security Advisories** ("Security" tab -> "Report a vulnerability" in this repository). We will acknowledge receipt within 48 hours and work with you on a coordinated fix and release.
